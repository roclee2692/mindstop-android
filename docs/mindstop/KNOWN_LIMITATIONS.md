# 知止 Mindstop 已知限制与设计边界（MVP 0.2）

更新日期：2026-11-26（对应 `mindstop` 分支阶段 0–6 完成态）。

## 1. 架构与产品边界（按 SPEC-MVP-0.2.md 主动克制）

- **本地优先、无云同步**：所有规则、额度、使用片段、意图、题库、成长记录、复盘与专注数据仅存于本机 Room 数据库（`mindstop_db` v6），不上传任何服务器。
- **独立学习模式为「自报」口径**：不通过 OCR、视频内容识别或屏幕截图监控判定用户是否在真学习；统计与首页均明确标注「学习模式使用（自报）」，绝不展示为「已验证有效学习时间」。
- **成长世界单视觉主题**：MVP 0.2 采用原生 2D Canvas 轻绘「森林花园」主题；生态岛屿、虚拟宠物主题已通过领域模型 `GrowthWorldState` 解耦预留，不阻塞首版交付。
- **睡前早起模块预留**：`BedtimeSettings` 与 `WakeupPlan` 已预留 `plannedWakeMinutesOfDay` 及 `MANUAL`/`QR`/`NFC` 确认枚举；完整 `AlarmManager` 精确闹钟与离床验证属于后续版本。
- **CSV 题库导入**：支持 UTF-8（含 BOM）、标准引号/逗号转义、中文与行级错误提示；按需求不直接解析 `.xlsx` 文件，也不做在线协作编辑器或实时 AI 出题。

## 2. 工程与系统兼容性限制

- **HyperOS / MIUI 后台限制**：必须同时开启无障碍服务、省电策略「无限制」、自启动和「后台弹出界面（op 10021）」，否则后台定时与跨应用弹窗会被系统拦截。诊断页已内置对应检测与直达入口。
- **设置变更延迟未接入知止设置项**：意图设置、续时规则、奖励规则、睡前规则修改后立即生效，尚未接入 Curbox 原生的「设置变更延迟」机制。
- **睡前夜间最大续期次数粒度**：当夜间最大续期次数设为 `0` 时，睡前时段完全禁用答题续期；设为 `1–5` 时目前沿用当天续期档位，尚未做夜间独立计数器。
- **轻量复盘触发场景**：目前在结束「学习模式」会话时自动弹出；娱乐显著超时自动弹出复盘留待后续细化（用户始终可一键跳过，不做心理诊断）。
- **跨次冷静等待与系统时间**：冷静等待（`calm_wait`）与服务内可信时钟（`TrustedClockModel`）能抵御把系统时间往回拨或断网改表，但在服务未运行时手动把系统时间往后拨仍可能缩短跨次重开的冷静等待。
- **上游遗留接收器与测试**：
  - 5 个继承自 Curbox 的 `RECEIVER_EXPORTED` 广播接收器沿用原 action 名，若同机安装原版 Curbox 可能互相收到广播。
  - 上游单元测试 `ScriptLanguageTest.matchesRegexSupportsCommonFlags` 在未改动基线上即失败，与知止功能无关。
  - 上游包含阿拉伯语、德语、俄语等 9 种多语言文件，导致 `lintFullDebug` 对知止中英双语字符串报告 `MissingTranslation`（知止自身逻辑与布局 0 Error）。
