# 知止 MindStop —— 新增功能开发需求（v0.3 扩展规格原文）

记录日期：2026-11-26（用户原需求逐字留档，以本文为准）。

## 1. 本次开发范围

在现有 MindStop Android 项目基础上，新增三个相互关联的功能模块：

- 夜间收尾（Bedtime Wind-down）
- 晨间启动（Morning Activation）
- 购物决策（Intentional Shopping）

保留已有应用监控、意图确认、时间管理、挑战解锁、成长奖励、专注模式和行为统计功能。
不得重新创建项目、无意义地重构已有模块、修改已确定的品牌名称和 Logo，或破坏已经实现的功能。
新增模块应尽可能复用现有规则引擎、会话引擎、奖励引擎及本地数据库。
产品的最终目标始终是帮助用户学会管理自己，而不是让程序替用户决定如何生活。

## 2. 开源项目复用候选

- 闹钟与晨间启动：Fossify Clock (`FossifyOrg/Clock`)、Upupup (`Purgator/Upupup`)、NFC Alarm Clock (`gabeg805/NFC-Alarm-Clock`)
- 购物决策与预算：PriceGrab (`mablanco/pricegrab`)、Ivy Wallet (`Ivy-Apps/ivy-wallet`，已停止维护，仅参考)
- 长期行为统计：Loop Habit Tracker (`iSoron/uhabits`)

## 3–8. 模块一：夜间收尾

- 睡眠计划：计划睡眠时间、计划起床时间、最晚娱乐结束时间、睡前缓冲时间、夜间限制应用及分组、工作日与休息日独立计划、希望保留的晚间自由休息时间；计算计划睡眠机会时长；区分计划睡眠时长与实际睡眠时长。
- 渐进式夜间收尾：可配置节点（例如 22:00 自由休息 / 22:30 提醒准备结束 / 22:45 显示剩余时间 / 22:50 结束娱乐进入缓冲 / 23:00 睡眠保护时段），显示剩余娱乐时间、明天起床计划及当前延迟对计划睡眠机会的影响；避免恐吓或制造睡眠焦虑。
- 夜间限制策略：限制指定短视频/游戏/购物应用，保留必要通信/闹钟/阅读/音乐/紧急功能，支持灰度/低刺激可选，独立夜间续期规则、延长冷却或限制至次日指定时间，保留主动解除能力；夜间默认不推荐高强度数学挑战。
- 睡前正向奖励：计划时间内主动结束娱乐立即展示安静低亮度的银杏成长反馈并生成待确认奖励，后台验证未重入后自动确认；超时后立即停止也可获恢复控制部分奖励；不清空历史成就。
- 夜间行为记录：计划娱乐结束时间、实际最后一次受监管应用使用时间、睡前娱乐超时时长、夜间重开次数、主动结束与强制拦截情况、用户可选填写的实际入睡时间（非医学级睡眠监测）。

## 9–14. 模块二：晨间启动

- 基础闹钟：单次与重复、工作日与休息日、自定义铃声与渐进音量、振动与贪睡、锁屏响铃、可选数学（复用现有 `ChallengeEngine`）/步数/二维码/NFC 验证、重启恢复、精确闹钟权限与状态诊断；须经真机测试。
- 醒后 15 分钟启动计划（可自定义）：响应闹钟（轻量正向反馈）→ 身体唤醒（默认 5 分钟，预设简单活动）→ 晨间期待（默认 10 分钟，期待活动，数字娱乐独立额度防沉迷）。
- 防重新入睡状态机：`Scheduled → Ringing → Acknowledged → Activation → Completed / ReturnedToBed / Unverified`，支持第 5/15 分钟轻量确认、可选备用闹钟、运动/操作辅助信号（非确定证据），不持续响铃或无限验证。
- 晨间奖励：响应闹钟发待确认奖励，完成启动后确认；回床可撤销待确认奖励但不影响历史成就；不奖励睡眠不足极端早起。
- 睡前与晨间联动：共用同一份个人作息计划，统计夜间超时、闹钟响应延迟、启动完成时间、自报回床、实际起床时间及晨间奖励使用情况。

## 15–26. 模块三：购物决策

- 购物应用启动意图：淘宝/京东/拼多多/闲鱼等购物分组；区分购买计划商品、查物流、联系客服、处理售后、评价、随便逛逛（事务类免填预算，逛逛配独立浏览时长与暂存入口）。
- 购买意图确认：商品名称、购买目的、预算、重要/紧迫程度、必要条件、偏好条件、一键复制搜索词、悬浮目标与剩余搜索时间。
- 决策分级：低价低影响 5–10m / 普通日用品 10–20m / 中等价值 20–40m / 贵重耐用品分多次每次 30–45m（可配置）。
- 商品候选池：手动添加与 Android 分享导入商品链接；规格/数量/单位/价格/优惠/运费/到手总价/必要条件/证据/售后/备注。
- 价格标准化：仅可比商品同组比较；参考 PriceGrab 用精确货币/数值类型（`BigDecimal` / 分）计算单位价格。
- 价格分位数分析：最低、最高、均值、P25、P50、P75（明确插值算法+单测）；样本不足提示不稳定；显示样本数、时间与来源。
- 购物停止规则：3-2-1 决策法、满意决策提示、可选搜索成本估算（明确标记为用户假设）；最终决定权归用户。
- 贵重商品研究模式：研究时间与购买冷却分开、多次会话累计研究时长、未解决问题、历史价格、决策日期、自定义冷却期。
- 新增需求缓冲池：一键保存非计划商品、默认 24 小时冷却（可调/可手动取消）、紧急合理需求可直接确认。
- 轻量消费预算：7 分类（餐饮/日用品/衣物/学习及工作用品/耐用品/兴趣娱乐/其他）、月度与自由预算、手动确认实际支出（与候选价严格区分）、支持退货退款调整。
- 购物奖励：奖励明确目的、合理时间完成决策、满足后退出、非紧急入缓冲池、停止无价值比价、完成阶段研究；同任务防刷。

## 27–31. 通用工程要求、开发优先级与交付边界

- 复用现有规则/会话/干预/挑战/奖励引擎与本地存储，不新增底部 Tab，所有成就统一入成长世界。
- 优先级：第一阶段 夜间收尾 → 第二阶段 晨间启动 → 第三阶段 购物决策基础 → 第四阶段 价格分析与决策支持。
- 每完成一个阶段进行单元测试、集成测试和必要真机验证。
